# Resume Projects

## Projects

| Project | What it is |
|---|---|
| [Ocean Data ML Platform with RAG](./Ocean%20Data%20ML%20Platform%20with%20RAG) | An end-to-end pipeline that ingests raw NetCDF ocean sensor data from two independent providers, harmonizes it with Apache Spark, trains an XGBoost temperature forecaster, and exposes a retrieval-augmented question-answering interface over the resulting metadata. FastAPI service, Qdrant vector store, Docker Compose. **[Demo with live responses from every endpoint](./Ocean%20Data%20ML%20Platform%20with%20RAG#demo)** |
| [Stock Sentiment Analysis](./Stock%20Sentiment%20Analysis) | An end-to-end quantitative data pipeline that integrates social media sentiment with financial time-series data to evaluate whether influencer-driven online discussions are associated with stock returns and market volatility. Neo4j and SQLite, FinTwitBERT, Granger causality and GARCH. |
| [Distributed Facility Reservation System](./Distributed%20Facility%20Reservation%20System) | 27 versioned REST endpoints with published OpenAPI documentation, 71 pytest tests across the API, database and reservation rules, and one booking contract negotiated with four other teams. Built at UChicago in a team of 4. |
| [Parallel Image Processing Engine](./Parallel%20Image%20Processing%20Engine) | An image processing engine in Go supporting grayscale, sharpening, blurring and edge detection through custom 2D convolution kernels, with sequential, fan-out pipeline and bulk synchronous parallel execution models. |
